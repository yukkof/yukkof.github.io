========================================
  软件站 · 使用说明
========================================

一、这是个什么东西
----------------------------------------
一个纯静态网站：一个首页列出所有软件，每个软件有自己的独立页面和网址。
不需要服务器、不需要数据库，做好之后放到 GitHub Pages 上就能用，还可以绑自己的域名。

二、文件夹里都是什么
----------------------------------------
  data/apps.json        <<< 你唯一需要改的文件，所有软件信息都在这里
  templates/            页面模板（不要动，除非我让你动）
  assets/site.css       样式（颜色、间距都在这）
  assets/site.js        交互（明暗切换、搜索、分类筛选）
  build.py              生成器：把 json 变成网页
  更新网站.bat          双击它 = 重新生成整站
  index.html            生成出来的首页（不要手改，会被覆盖）
  apps/<名字>/index.html 生成出来的软件页（不要手改，会被覆盖）

三、日常怎么加一个软件（3 步）
----------------------------------------
1. 打开 data/apps.json
2. 在 "apps": [ ... ] 里面，复制一段现有的 { ... } 整块，
   粘在最后一个的后面，把内容改成新软件的。
   注意：两块之间要有英文逗号 , 隔开。最后一块后面不要逗号。
3. 双击「更新网站.bat」，看到「完成」就好了，双击 index.html 看效果。

四、apps.json 每个字段的意思
----------------------------------------
slug        网址用的英文名，只能用英文小写和短横线，例如 duskflow、quote-tool
            一旦发布就不要再改，改了网址就变了，别人收藏的链接会失效
name        软件名称，显示在网页上，中文英文都行
tagline     一句话介绍，20 字以内最好，显示在卡片上
platforms   平台列表，例如 ["Windows"] 或 ["Android"] 或 ["Windows","Web"]
            首页的分类按钮是自动从这生成的
status      状态：released=已发布 / beta=测试版 / coming=即将上线
version     版本号，例如 "1.2.0"（不写前缀 v，程序自己加）
updated     更新日期，例如 "2026-11-01"
size        安装包体积，例如 "24 MB"
icon        图标路径，例如 "assets/icons/duskflow.png"
            留空的话会自动显示软件名的第一个字，也好看
screenshots 截图路径列表，例如 ["assets/shots/duskflow-1.png", "assets/shots/duskflow-2.png"]
            留空会显示一个「截图待补」的虚线框
description 详细介绍，一两段话，写清楚解决什么问题、适合谁用
features    功能点列表，3-5 条最好
changelog   更新记录，每项有 version / date / notes（notes 是字符串列表）

五、下载按钮怎么写（三种情况）
----------------------------------------
【1】免费的，放在 GitHub Releases：
    "download": {
      "type": "github",
      "url": "https://github.com/你的用户名/仓库/releases/latest",
      "note": "从 GitHub 下载，永久免费。"
    }

【2】上架了应用市场的（网站只做介绍，跳过去下载）：
    "download": {
      "type": "store",
      "note": "在应用市场安装，更新由市场自动推送。",
      "stores": [
        { "name": "App Store", "url": "https://apps.apple.com/app/id123456" },
        { "name": "Google Play", "url": "https://play.google.com/store/apps/details?id=xxx" }
      ]
    }
    第一个按钮是实心的，后面的是描边的。

【3】还没做完 / 不对外发布：
    "download": {
      "type": "none",
      "note": "还在做，做好了会放在这里。"
    }

【4】小文件想直接放网站上（不建议放超过 50MB 的）：
    "download": { "type": "direct", "url": "files/setup.exe" }
    文件放到项目里的 files/ 文件夹，路径写相对路径。

六、图标和截图放哪
----------------------------------------
在项目里建两个文件夹：
  assets/icons/    放图标，建议 512x512 的 PNG，方图
  assets/shots/    放截图，竖版手机截图最好高度一致
放好之后，把路径填进 json 就行，注意用正斜杠 / 不要用反斜杠 \

七、经常遇到的报错
----------------------------------------
「apps.json 格式有问题，第 X 行第 Y 列」
  九成是：多了一个逗号、少了一个逗号、引号用了中文的“”，
  或者 json 里写了注释（json 不支持注释）。

双击 bat 一闪就没了
  Python 没装好或者没加到 PATH，把 bat 里的 python 改成完整路径试试。

八、发布上线
----------------------------------------
这一步需要 GitHub 账号，等网站内容填好了我再带你走。
生成出来的东西（index.html、apps/、assets/）推上去就能访问。

七、中英文切换（2026-11-19 新增）
────────────────────────────────────────
网页右上角有「中 / EN」两个按钮，访客点一下整站换语言，选择会记在浏览器里。

要让它真的中英双语，apps.json 里每个软件可以补这几个字段（不填就显示中文）：
  nameEn          英文名
  taglineEn       英文一句话介绍
  descriptionEn   英文详细介绍
  featuresEn      英文功能列表（数组，和 features 一一对应）
  download.noteEn      下载说明的英文
站点本身也有：
  site.nameEn     英文站名
  site.taglineEn  英文大标题
  site.introEn    英文简介

界面上的按钮、标题（浏览全部 / 功能 / 截图 / 更新记录 / 获取这个软件 …）
是页面自带的词典，不用你管，自动跟着切。
